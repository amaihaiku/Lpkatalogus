## 2024-05-17 - Fast rendering by skipping clean rows
**Learning:** In the ZX Spectrum emulator running on ESP32, the screen rendering process translates ZX Spectrum attribute and pixel bitplanes into TFT-compatible 16-bit colors. Processing all 24x32 blocks block-by-block even when unchanged is a significant CPU bottleneck. Checking differences row-by-row using `memcmp` on 32-byte chunks before embarking on pixel mapping provides a massive speedup by safely skipping entire rows.
**Action:** Always look for opportunities to perform fast aggregate checks (like `memcmp`) to bypass complex, per-pixel or per-character recalculations in graphics loops. Always remember to check for temporal conditions (like the ZX Spectrum flash attribute) that require redraws even when underlying memory is unchanged.
